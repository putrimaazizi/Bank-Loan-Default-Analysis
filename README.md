# Bank-Loan-Default-Analysis
Background :
Pemberian pinjaman (loan) adalah salah satu aktivitas utama perbankan dan lembaga keuangan. Proses persetujuan pinjaman melibatkan penilaian risiko untuk menentukan apakah seorang pemohon layak menerima kredit atau tidak. 

Objective of Analysis : 
1. Menganalisis faktor-faktor yang berhubungan dengan persetujuan atau penolakan pinjaman.
2. Menemukan pola demografis, finansial, dan historis yang mempengaruhi kelayakan kredit.
3. Memberikan insight berbasis data untuk membantu meningkatkan proses pengambilan keputusan dalam pemberian pinjaman.
